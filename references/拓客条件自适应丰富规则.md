# 拓客条件自适应丰富规则

> AI 辅助搜索的核心规则：用户给模糊需求，AI 自动补全成一套合理的风鸟高级搜索条件。

## 目标

用户一句话描述需求（"帮我找卖电脑的公司"），AI 识别意图 + 自动补全条件，直接生成可执行的搜索参数。

## 条件丰富模板（默认最佳实践，已沉淀）

| 维度 | 默认策略 | 参数/取值 |
|---|---|---|
| 经营范围 | 从需求提取核心词 | 卖电脑→`计算机销售`、做安防→`安防设备`、搞软件→`软件开发`、卖服务器→`服务器` |
| 注册资本 | 中小型 100-1000万 | `regcap=100￥1000`（过滤巨头和空壳） |
| 企业状态 | 在营/存续 | `status=1`（排除注销/吊销/停业） |
| 企业类型 | 有限责任公司 | `enttype=有限责任公司代码`（排除个体户） |
| 行业 | IT 相关 | `nicid=I65软件/I64互联网/F51批发/I63电信` |
| 联系方式 | 有手机 | `contact=has_lianxi_phone`（方便直接触达） |
| 客户类型 | 根据需求判断 | 渠道商/经销商 或 集成商/项目商 |

## 常见需求 → 条件映射（示例）

| 用户说 | AI 补全为 |
|---|---|
| 找卖电脑的公司 | 计算机销售 + 渠道商/经销商 + 100-1000万 + 存续 + 有限责任公司 + 有手机 |
| 找做系统集成的 | 系统集成 + 集成商/项目商 + 100-1000万 + 存续 + 有手机 |
| 找北京卖服务器的 | 服务器 + 渠道商/经销商 + 地区=北京 + 100-1000万 + 存续 |
| 找有中标记录的集成商 | 系统集成 + 集成商 + has_bid_win + 100-1000万 + 存续 |
| 找成立5年以上的老渠道 | 计算机销售 + 渠道商 + esdate=10￥5 + 100-1000万 + 存续 |

## 补全逻辑（AI 处理步骤）

1. **提取核心经营范围词**：从用户描述识别"卖什么/做什么"（卖电脑→计算机销售、卖服务器→服务器、做安防→安防设备…）
2. **判断客户类型**：找经销商/渠道→渠道商/经销商；找做项目/集成→集成商/项目商
3. **套用默认条件**：中小型注册资本 + 存续状态 + 有限责任公司 + IT行业 + 有手机（这5个是通用兜底，除非用户另有要求）
4. **用户明确指定的优先**：用户说了"北京""500万以上""有中标"，就按用户说的，不再用默认

## 关键约束

- 风鸟经营范围：**加号`+`=同时包含(AND)**，逗号=任一(OR)。要"计算机销售且系统集成"用`计算机销售+系统集成`
- 注册资本上限默认 1000万（中小型），用户说"找大的"再放开
- 状态必须 `status=1`（在营/存续），拓客不需要注销吊销的
- 结果要能联系上，默认筛"有手机/有邮箱"
