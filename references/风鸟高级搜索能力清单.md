# 风鸟高级搜索 API 能力清单

> 逆向自风鸟"找客户"（高级搜索）页面，字段取值均实测确认。2026-08-18 固化。

## API 端点

```
POST https://www.riskbird.com/riskbird-api/api/v1/senior-search/search
```

请求体：`{"aoData": "<json字符串>", "queryType": "senior", "queryLimitType": 2}`
其中 aoData 是 DataTables 格式，核心是 `cSearch_conditionData` 对象（以下所有筛选字段都在这个对象里）。

## 返回字段

返回 `aaData` 数组，每家有：`id`(企业entid)、`name`(企业名)、`contact`(电话,打码)、`email`(邮箱,打码)、`frname`(法人)、`status`(状态)、`regCap`(注册资本)、`entType`(企业类型)、`regDate`(成立日期)、`creditNo`(统一社会信用代码)

## 分页

`iDisplayStart`(起始) + `iDisplayLength`(每页条数)，`totalCount` 给总数。

## 关键结论

1. **经营范围多词**：加号`+`或空格 = 同时包含(AND)，逗号`,` = 任一包含(OR)。
2. **状态筛选**：`status=1` 只出在营/存续企业（拓客必备，过滤注销吊销停业）。
3. **中标/招标/专利/商标/软著/备案**：都是布尔 `"1"`，可组合筛"有真实经营痕迹"的企业。
4. **联系方式**：列表页电话邮箱打码，但高级搜索能筛"有手机/有邮箱/有固定电话"，配合 riskbird_batch 补全完整电话。
5. **列表页返回**：`contact`/`email` 打码（`130******`），完整电话靠"查公司"搜索免费拿。

## 拓客适配建议

- **渠道商/集成商拓客**（本技能主场景）：`opscope`=身份核心词+叠加词（加号AND）、`status=1`、`regcap`=100-1000万、`enttype`=有限责任公司、`nicid`=IT行业、`contact`=有手机/有邮箱
- **终端客户**：风鸟高级搜索**不适合**直接找终端（经营范围关键词对不上终端采购方），建议另找招投标/采购数据源
